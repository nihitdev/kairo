One command

Start with a preview.

Curl and Wget clone Kairo to ~/kairo, request sudo, and open the full installer. Existing local work is never overwritten.

curl -fsSL https://raw.githubusercontent.com/nihitdev/kairo/main/install.sh | bash

Designed for confidence

A guided install.
Not a blind script.

Kairo discovers the machine, lets you choose the surface area, and shows the consequences before it writes.

  1. 01

    Detect

    Arch, architecture, shell, session, package tools, and systemd.

  2. 02

    Choose

    Dotfiles and toolchain profiles selected independently.

  3. 03

    Review

    Missing packages, replacements, trust changes, and backup status.

  4. 04

    Apply

    Packages, staged configs, shell integration, caches, and validation.

Built to back out

Safety is part
of the interface.

The installer’s visual polish sits on top of conservative filesystem behavior—not instead of it.

  • ✓
    Private, unique backupsEvery run gets a restrictive timestamped backup directory.
  • ✓
    Transactional replacementPayloads stage beside their target before activation.
  • ✓
    Reverse-order rollbackA failed operation restores completed replacements.
  • ✓
    Strict path boundariesTraversal, root targets, and symlink escapes are rejected.
  • ✓
    Actually dryDry-run performs no package, plugin, cache, or config writes.
