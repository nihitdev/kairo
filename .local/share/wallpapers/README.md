# Curated desktop wallpapers

The `archnemesis` folder contains exactly 25 images, with no nested folders:

- 18 images from **CozyPixels / Catppuccin / Space & Cosmic**.
- Four maintainer-supplied snow wallpapers: `snow-pine-forest.png`, `snow-night-moon.png`, `snow-desert-sunset.jpg`, and `snow-mountain-range.jpg`.

- Three additional maintainer-supplied images: `Clouds.jpg`, `Girl-Shooter.png`, and `Mahoraga.jpg`.

Only these image files are copied directly into `~/Pictures/Wallpapers`. No Nord or One Dark collections, preview READMEs, or full CozyPixels checkout are installed. Fresh Hyprland installs select `snow-pine-forest.png`; existing personal files and wallpaper choices are preserved.

Upstream: https://github.com/SleepyCatHey/CozyPixels. The upstream MIT license is preserved beside this file as `CozyPixels-LICENSE`, outside the installable images folder.
