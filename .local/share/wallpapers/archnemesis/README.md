# Curated desktop wallpapers

40 images: `snow-pine-forest.png`, `snow-night-moon.png`, and the Space & Cosmic collections from CozyPixels Catppuccin, Nord, and One Dark. The snow images were supplied from the maintainer's Downloads folder. The CozyPixels subset comes from https://github.com/SleepyCatHey/CozyPixels and retains its directory structure, preview READMEs, and upstream MIT license in `CozyPixels/LICENSE`.

Fresh Hyprland installs use `snow-pine-forest.png`. These files are copied into `~/Pictures/Wallpapers` without replacing existing files. No CozyPixels repository clone is required.
